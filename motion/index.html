Paper explainer

Agentic AI-based Autonomous Software Development Organization

Eight LLM agents, mapped onto the five TSPi roles, turn a one-sentence idea into specifications. A deterministic renderer then builds a runnable app, so "does it build?" measures specification quality without a human judge.

1 · The system

From idea to running app

Artifacts flow through six agents in fixed order. Only the reasoning stage is generative; the final render step makes no LLM calls.

The Project Manager sequences the agents; the Quality role's report is displayed but consumed by nothing.

2 · The experiment

Same agents, different wiring

Roles, prompts, model and temperature are held identical (verified byte-for-byte). Only coordination changes.

3 · The result

No quality difference. A big cost difference.

Every run completed and every specification built, so quality sits at a ceiling. What separates the conditions is wall-clock time.

4 · Where time goes

5 · Takeaways

Three findings that hold up

−16.8%

Topology is a free lever

Unified crew vs federated: faster for all 5 projects, paired t(4) = 4.19, p = 0.014. One pipeline, one model.

−56.7 s

Advisory roles cost, not contribute

Removing the Quality role saved about its own runtime and changed nothing else, because no agent consumes its verdict.

≈47%

One schema drives cost

The Design agent takes 46.9% (federated) and 48.6% (unified) of pipeline time.

Open question: whether decomposition improves specification quality. That needs coverage-sensitive metrics and harder inputs.
